# LeetCode practice

Keep each problem in a separate Python file in this folder, for example:

```text
leetcode/
    lfu/
        lfu_cache.py
    two_sum.py
    valid_parentheses.py
```

`lfu_cache.py` is ready to run. The other filenames are suggestions for future problems.

In PyCharm, open a problem file and right-click → Run to see its examples and explanations.

From the project root, you can also run:

```sh
.venv/bin/python leetcode/lfu/lfu_cache.py
```

Put each problem's examples under `if __name__ == "__main__":` so they run only when you run that file directly.
